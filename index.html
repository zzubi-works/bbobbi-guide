비공개 시험 · rc9.7

뽀삐 서버 설치 안내

와 줘서 고마워요! 마음껏 놀면서 이상한 점을 알려 주세요. 설치는 10분이면 끝나요. rc9.7부터 모두 처음부터 시작해요.

서버 주소
mc.erp.pictures
Minecraft Java 1.21.1NeoForge 모드팩포트 입력 필요 없음

준비물

  • Minecraft Java 계정. 정품(Microsoft 로그인)이면 가장 쉬워요. 비공개 시험 동안은 정품 인증을 꺼 두어서 정품이 없어도 들어올 수 있어요(아래 "정품 계정이 없을 때").
  • PC 메모리 16GB 이상을 권해요(8GB면 셰이더를 꺼야 해요). 자바는 런처가 알아서 받아요.
  • 받을 파일 하나: 뽀삐-비공개시험-rc9.7.mrpack (약 1.7GB). 운영자가 구글 드라이브 링크로 줘요. 모드·셰이더·텍스처팩이 모두 들어 있어요.
  • 예전 파일(rc9.3 이하)로는 들어올 수 없어요. "예전 팩 파일이에요. 뽀삐-비공개시험-rc9.7로 다시 설치해 주세요."가 뜨면 새 파일로 다시 설치해요.

설치하기 (Modrinth App)

  1. modrinth.com/app에서 Modrinth App을 받아 설치하고, Microsoft 계정으로 로그인해요.
  2. 왼쪽 위 + 버튼(인스턴스 만들기)을 눌러요.
  3. 아래쪽 파일에서 가져오기를 누르고 받은 .mrpack 파일을 골라요.
  4. 모드는 파일 안에 다 들어 있어서 따로 받지 않아요. 앱은 마인크래프트와 NeoForge만 받아요. 1~2분 기다려요.
  5. 인스턴스 설정 → Java와 메모리에서 메모리를 8192MB(8GB)로 올려요. 최소 6GB예요. 5GB 이하면 멈추거나 튕기고, 12GB 넘게 주면 오히려 끊길 수 있어요.
  6. 플레이 → 멀티플레이 → 서버 추가에서 주소 mc.erp.pictures를 넣고 접속해요.

모드 몇 개가 "알 수 없는 파일"이라고 나와도 괜찮아요. 이름이 낯선 모드는 우리 서버 전용 모드예요.

Modrinth App이 안 될 때 (Prism Launcher)
  1. prismlauncher.org에서 Prism Launcher를 설치하고 Microsoft 계정을 추가해요.
  2. 인스턴스 추가 → 가져오기에서 같은 뽀삐-비공개시험-rc9.7.mrpack 파일을 골라요.
  3. 인스턴스 편집 → 설정 → Java에서 최대 메모리를 8192MB로 맞춰요(최소 6GB).
  4. 실행 → 멀티플레이 → 주소 mc.erp.pictures.
정품 계정이 없을 때 (Prism Launcher 오프라인 계정)
  1. Prism Launcher를 설치하고 계정 → 추가 → 오프라인을 골라 게임 안에서 쓸 이름을 넣어요. Prism은 처음 한 번 Microsoft 계정이 있어야 오프라인 계정을 만들 수 있어요.
  2. 그 계정을 기본으로 고른 뒤 위 Prism 순서대로 .mrpack을 가져와 접속해요.
  3. 이름이 곧 내 캐릭터예요. 다른 사람과 같은 이름은 쓰지 마세요. 이름을 바꾸면 새 캐릭터가 돼요. 운영자 이름은 쓰지 마세요.
예전 파일(rc9.3 이하)로 설치했던 사람
  1. rc9.7 파일을 위와 같이 새 인스턴스로 가져와요. 예전 인스턴스에 덮어 올리지 않아요. 빠진 모드가 남아 접속이 막혀요.
  2. 메모리를 다시 8192MB로 맞추고 접속해요. 예전 인스턴스는 지워도 돼요.
  3. 처음 실행할 때 아래 기본 단축키가 한 번 맞춰져요. 그 뒤에 바꾼 키는 그대로 둬요.

처음 30분

  1. 처음 들어오면 짧은 이야기와 함께 "당신의 이름은?"을 물어요. 섬에서는 모두가 그 이름으로 불러요(2~8자, 나중에 시민 등록소 윤슬에게서 바꿀 수 있어요). rc9.7부터 모두 처음부터 시작해서, 예전에 하던 분도 프롤로그부터 봐요.
  2. 열차에서 내리면 1번 승강장이에요. 안내원 하나의 이야기를 따라가고, 할 일은 퀘스트 저널(J)에서 봐요.
  3. 시청 시민 등록소 윤슬에게서 시민증을 만들어요. 정착금과 무료 원룸을 받아요.
  4. E를 누르면 왼쪽에 내 캐릭터·장비, 오른쪽에 소지품이 나와요. 위 아이콘으로 포켓몬·퀘스트·도감 창을 열어요.
  5. 화면 아래가 새 모양이에요. 왼쪽 아래 체력·배고픔, 오른쪽 아래 든 물건, 위에 나침반이에요. 이상하면 E → 설정 → 'HUD: 마크 기본'.
  • 돈(G)은 게임 안에서만 벌고 써요. 현금 결제는 없어요.
  • 음성 채팅이 돼요. V를 누르는 동안 말해요. 마이크·스피커는 ; 음성 화면에서 골라요.
  • 탐험대륙·레이드전선은 중앙역 승강장에서 가요. 다른 서버로 자동으로 옮겨지고, 돌아올 때도 자동이에요.

그래픽 (셰이더·텍스처팩)

처음 실행할 때 한 번 셰이더(BSL)와 실사 텍스처팩(Misa's Realistic 64x)이 켜져요. 그 뒤에 끈 것은 팩을 새로 받아도 그대로예요.

  • F6: 셰이더 켜기/끄기
  • 설정 → 비디오 설정 → 셰이더 팩: 셰이더 고르기·끄기. PC가 약하면 끄거나 가벼운 MakeUp Ultra Fast를 골라요
  • 설정 → 리소스 팩: 텍스처팩 켜기/끄기 (Better Leaves 잎·Fast Better Grass 풀도 들어 있어요, 처음엔 꺼짐)

만든 사람: BSL Shaders(capttatsu), Misa's Realistic(Misa_64), Entity Texture/Model Features(Traben), MakeUp Ultra Fast(javiergcim), Better Leaves(Motschen), Fast Better Grass(Fabulously Optimized), Sodium·Iris(CaffeineMC·IrisShaders). 라이선스는 인스턴스 폴더 licenses/에 있어요.

자주 막히는 것

증상이렇게 해 봐요
로딩 중 멈춤·튕김, "Out of memory"메모리를 8GB로 올려요(최소 6GB). 크롬 탭 같은 다른 프로그램을 닫아요.
"예전 팩 파일이에요", "Incompatible client", 모드 목록이 다르다는 창운영자가 새 팩을 줬다면 인스턴스를 지우고 새 파일로 다시 가져와요.
접속 거부, "연결 시간 초과"주소 mc.erp.pictures를 다시 확인해요. 그래도 안 되면 운영자에게 알려 줘요. 점검 중일 수 있어요.
음성이 안 들림; 음성 화면에서 마이크·스피커 장치를 골라요. 회사·학교 망에서는 음성이 막힐 수 있어요.
느림·끊김먼저 F6로 셰이더를 꺼요. 그래도 느리면 비디오 설정에서 렌더 거리 8 이하. 노트북이면 충전기를 꽂아요.
